## CircuitPython Examples

### LED Examples for Qt Py / Xiao2040

- **qtpy_blink_leds.py** - Basic LED blinking example that turns 3 LEDs on and off simultaneously
- **qtpy_fade_leds_sequence.py** - Sequential LED fading using PWM. Each LED fades up to full brightness and back down to zero, one at a time in sequence

Both examples use LEDs connected to pins A0, A1, and A2 with 220Ω resistors.
